# Agent workspace

This directory is a persimmon Task workspace. persimmon records what you produce as artifacts;
you do not manage history here.

- Never run git: no `git add`, `git commit`, `git init`, no branches.
- Write only inside this directory. Do not change `package.json` or `vitest.config.mjs`; add no dependencies.
- Rules from directories above this one do not apply here.
